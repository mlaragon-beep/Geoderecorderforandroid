# Android Internal Recorder (Geode Mod)

Zero-lag hardware-accelerated internal video and FMOD audio recorder for Geometry Dash on Android.

## Quick Build on Phone (No PC Needed)
1. Unzip this folder and upload all files to a new repository on GitHub (keep the folder structure `src/` and `.github/workflows/` intact).
2. Open the **Actions** tab in your GitHub repository and wait ~2 minutes for **Build Geode Mod** to finish.
3. Tap the finished workflow run -> **Artifacts** -> download `android64` to get your compiled `.geode` file.
4. Install the `.geode` file inside Geode Launcher.
